## Исправление отображения на Vercel

Ранее `vite build` публиковал интерфейс, а паспорта были доступны только через Express/SQLite `/api/places`. На статическом хостинге без этого сервера архив не загружался. Теперь сборка также содержит `catalogue/places.json` со всеми 36 публичными паспортами; приложение использует его при недоступном API. Настройки Vite-сборки для Vercel записаны в `vercel.json`.

Отдельный браузерный запуск намеренно не создаёт БД и API и возвращает HTML оболочки по неизвестным путям. В нём проверены 36 карточек, поиск Немчиновой, паспорт и источник, 35 отключённых по умолчанию координатных гипотез, избранное после перезагрузки, прямая ссылка на Кедровый, 36 историй, мобильный экран и отсутствие попыток отправки данных через недоступные формы. Быстрое переключение страницы после масштабирования карты также не вызывает исключение: отключена отложенная анимация масштаба Leaflet, способная обратиться к уже удалённой карте.

Адрес пользователя `https://karta-git-main-sup-surgut.vercel.app/` при анонимном запросе перенаправляет на вход Vercel. Защита не обходилась; проверка отображения выполнена на локальной production-сборке в условиях статического хостинга. Приём новых материалов и редакторская модерация требуют полного сервера с постоянным диском.

Публичные карточки очищены от идентификаторов PAS, отметок владельца и даты проверки, вводного абзаца импорта, служебного названия DOCX и параметров извлечения. Браузерные сценарии проверяют отсутствие этих строк при сохранении истории, сведений о местоположении и источников.
