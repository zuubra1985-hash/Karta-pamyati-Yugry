# Проверка приложения

Проверено 29 октября 2026 года: Node.js 24.19.0, Chromium, production-сборка Vite со строгой проверкой TypeScript.

- `npm test`: 32 теста, без ошибок и пропусков. Проверены приватность, модерация, авторизация, снимки, история и конфликты правок, обновление БД без потери данных, статический каталог, разбор координат и связь опубликованных воспоминаний с поселениями. Production API проверен на отсутствие служебного журнала цитат и разрешение iframe Яндекса в CSP.
- `npm run test:ui`: 22 браузерных сценария — 14 с полным сервером и 8 на статическом хостинге без API. Проверены фильтры и диапазон лет, избранное, отправка и редакторская правка, паспорт и источники, HTML как текст, мобильная навигация и отсутствие горизонтального переполнения. Исключений JavaScript нет.
- Координаты: десятичная точка/запятая и градусы, минуты, секунды нормализуются в числовые градусы. В Яндекс передаётся долгота/широта, в формы и Google — широта/долгота. Проверены отказ при перестановке осей, неправильных углах, неполной записи и выходе за область проекта.
- Карта: 32 реальные пары координат передаются в виджет Яндекса; приблизительные положения можно отключить; выбор паспорта фокусирует его точку; поиск по введённым координатам работает без API. Четыре объекта без координат не получают вымышленных точек. Переключение на OpenStreetMap и уход со страницы после изменения масштаба не вызывают отложенных ошибок Leaflet.
- Воспоминания: пять рассказчиков, пять публикаций, пять поселений; проверены источники, короткие цитаты, уникальность и правильная привязка. Пять карточек на общей странице, поиск рассказчика, переход к Нагорному с двумя воспоминаниями, понятный пустой результат поиска. Служебный журнал доказательств исключён из публичных данных.

В повторяемых UI-тестах сторонние виджеты и тайлы заменены тестовыми ответами: проверяется интеграция, а доступность поставщика не влияет на результат тестов. Отдельно настоящий виджет Яндекса загружен в Chromium через настроенный сетевой прокси: географическая подложка и все 32 точки отображаются. Для этой проверки собственные файлы production-сборки подставлялись как локальная тестовая страница с HTTPS origin, а внешние ресурсы Яндекса загружались из интернета. Это проверка собранного приложения, не анонимный просмотр защищённого адреса Vercel.

Скриншоты: [главная](desktop.png), [карта с 32 точками](map-hypotheses.png), [телефон](mobile.png), [карта на телефоне](map-mobile.png), [карточка Нагорного](passport-card.png), [воспоминания](memories.png). Подложка на скриншотах загружена из Яндекс Карт, атрибуция сохранена.

## Каталог и публикация

Сборка содержит `catalogue/places.json` с 36 паспортами и связанными воспоминаниями. При отсутствии API, HTML вместо JSON или сетевой ошибке приложение использует этот каталог. Успешный ответ полного сервера, включая намеренно пустой список, имеет приоритет. На статическом хостинге нет попыток записи через недоступные формы: приём материалов и кабинет редактора объясняют необходимость полного сервера до ввода личных данных.

Адрес `https://karta-git-main-sup-surgut.vercel.app/` при анонимном запросе перенаправляет на вход Vercel. Защита не обходилась. Карточки, поиск, воспоминания и просмотр координат работают в статической сборке; для сохранения новых материалов и редакторской модерации нужен полный сервер с постоянным диском.

Публичные карточки очищены от идентификаторов PAS, отметок владельца и даты проверки, абзаца импорта, служебного названия DOCX и параметров извлечения. Это отдельно проверяется в браузере при сохранении исторического текста и источников.

## Границы проверки исторических сведений

В каталоге 36 уникальных паспортов, 32 приблизительных местоположения, 6 объектов без точного года. Подтверждение владельца сохранено как происхождение комплекта; оно не является полевой проверкой координат. Результаты интернет-сверки и нерешённые вопросы перечислены в [FACT_CHECK.md](FACT_CHECK.md), источники воспоминаний — в [MEMORIES.md](MEMORIES.md).

До миграций созданы локальные резервные копии вне репозитория. Обновления проверены на сохранение правок владельца и удалённых записей; повторный импорт не дублирует карточки. Оригиналы DOCX/ZIP, рабочая SQLite-база, сессии, полные копии источников и зависимости не включены в Git. Репозиторий Splav не изменён.
