# Проверка версии 0.2

Проверено 28 октября 2026 года в текущей облачной среде: Node.js 24.19.0, Chromium.

- `npm test`: 18 тестов прошли, 0 ошибок, 0 пропусков. Покрыты приватность двух снимков, модерация и авторизация, безопасные ссылки, история правок и конфликты версий, обновление старой БД и импорт каталога без потери пользовательских данных.
- `npm run test:ui`: строгая проверка TypeScript, production-сборка Vite и 13 браузерных сценариев прошли. Исключений JavaScript нет.
- В браузере проверены поиск, тема, десятилетие и диапазон лет; соответствие маркеров фильтру; избранное после перезагрузки; сравнение снимков мышью/клавиатурой и рядом; отправка двух фото и паспорта; редакторская правка, история и публикация; защита от HTML-инъекции; тематические подборки и мобильная навигация.
